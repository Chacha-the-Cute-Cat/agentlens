核心设计

  • 单驱动：主控制设备 + Minifilter + WFP callout 合并，避免跨驱动通信。
  • 事件优先：内核只做可信观察和必要控制，分析在用户态。
  • 低锁策略热路径：COW immutable snapshot + path prefix tree + epoch-based deferred reclamation。
  • 上下文生命周期：引用计数、PID+CreateTime 校验、tombstone 延迟释放。
  • Registry Query：PostQuery 从调用者输出缓冲安全计算 ValueHash，避免热路径 ZwQueryValueKey 重入。
  • DNS 关联：用户态 ETW 消费 DNS Client，输出 remote_ip / dns_name。
